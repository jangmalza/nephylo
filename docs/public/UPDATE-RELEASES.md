# 자동 업데이트 서명

소스에는 공식 업데이트 검증 **공개키**만 포함합니다. 서명 개인키는 포함하지 않습니다. 포크 배포 전 [독립 배포 안내](../docs/OPEN-SOURCE.md#포크의-독립-배포)를 따라 자신의 업데이트 URL·키·설치 식별자를 구성하세요.

공식 공개 버전은 불변 산출물입니다. 공개한 같은 버전의 설치 파일·ZIP을 다시 빌드하거나 바꾸지 않습니다.

업데이트 봉투는 UTF-8 JSON payload의 Base64와 RSA-SHA256 서명을 포함합니다. payload는 schemaVersion, version, fileName, bytes, sha256 필드를 사용합니다. 클라이언트는 내장 공개키로 서명을 확인하고 다운로드 파일의 크기·SHA-256을 검증합니다.

`work/sign-release.ps1`은 `-PublicKeyPath`와 `-PrivateKeyPath`를 받습니다. 개인키는 현재 Windows 계정에 묶인 DPAPI 파일이며 저장소 밖에 보관합니다. 기존 공개키가 있는데 개인키가 없거나 다르면 서명을 중단합니다. 공식 키를 덮어쓰지 말고 독립 포크의 별도 경로를 지정하세요.

설치기 생성 절차는 [릴리스 안내](../docs/RELEASING.md)를 참고하세요. CI에 개인키를 넣거나 서명 검증을 끄는 방법으로 빌드·배포 문제를 해결하지 않습니다.
