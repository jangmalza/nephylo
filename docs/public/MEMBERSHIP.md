# 기존 회원 서버 코드

현재 무료 위젯은 Nephylo 회원 서버·로그인·결제를 사용하지 않습니다. 이 디렉터리는 기존 버전 호환을 위한 서버 코드, 마이그레이션, 설정 예제와 격리 테스트를 보존합니다. 운영 프로젝트 연결값과 실제 회원·결제 데이터는 포함하지 않습니다.

개발용 테스트는 이 폴더에서 `npm ci --ignore-scripts --no-audit --no-fund`와 `npm test`로 실행합니다. 테스트는 로컬 fixture를 사용합니다. `client-config.example.json`과 웹 `account-config.example.json`은 비활성 상태로 제공합니다.

자체 관리자 서버가 필요한 개발자는 자신의 프로젝트·인증 제공자·메일 설정을 별도로 구성해야 합니다. 공개 소스에 비밀 키나 사용자 세션을 넣지 마세요. 웹 공개 설정 입력·포크 방법은 [오픈소스 안내](../../docs/OPEN-SOURCE.md)에 있습니다. 이 저장소의 CI에는 공식 서비스의 인증 정보나 운영 배포 권한이 없습니다.
